# Architecture Blueprints (`/blueprints`)

This directory contains architecture diagrams and integration plans generated by the **Blueprint Agent**.

## Purpose

- System architecture documentation
- Integration blueprints for modules
- Design decisions and rationale
- Component diagrams

## Expected Outputs

The Blueprint Agent will create files here such as:
- `system-architecture.md` - Overall system design
- `module-integration.md` - How modules connect
- `data-flow.md` - Data flow diagrams
- `api-design.md` - API endpoint designs
