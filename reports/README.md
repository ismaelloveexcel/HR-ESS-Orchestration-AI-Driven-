# Research Reports (`/reports`)

This directory contains research findings generated by the **Research Agent**.

## Purpose

- Module evaluations and comparisons
- Best practices documentation
- Technology recommendations
- Vendor/tool assessments

## Expected Outputs

The Research Agent will create files here such as:
- `module-evaluation.md` - Scored comparison of HR modules
- `technology-stack.md` - Recommended technologies
- `uae-compliance.md` - UAE labor law requirements
- `integration-options.md` - Available integration approaches
